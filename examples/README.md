# pyradioss examples

Each directory holds a ready-to-run Radioss deck pair **plus the Python
script that generated it** (`generate_deck.py`) — modify the script, re-run
it, and re-run the solver to explore.

| Example | What it exercises | Expected result |
|---|---|---|
| `tensile_bar` | /BRICK solids, LAW2 Johnson–Cook, /BCS, /IMPVEL, /FUNCT, /TH | Axial stress tracks the JC curve `A + B·eps_p^n` (≈0.465 GPa at 2% strain); energy error < 0.1% |
| `box_beam_impact` | /SHELL Belytschko–Tsay, LAW2, /INIVEL, /RWALL, /GRNOD/PART | Progressive crush of the impacting end; ~75% of the kinetic energy converted to plastic work; energy error ~1% |
| `antenna_mast` | /BEAM Timoshenko beams (/PROP/TYPE3), /CLOAD + /FUNCT pulse, /BCS with rotations | Tip deflection peaks ≈23 mm (static F·H³/3EI = 22.5 mm), free vibration at the closed-form 69 ms period; energy error < 1% |
| `rubber_block` | /MAT/LAW42 Ogden hyperelasticity, nearly incompressible, /IMPVEL crush | 40% compression with visible lateral bulge (volume conservation); the time step drops as the rubber stiffens (LAW42's nonlinear sound speed); energy error ~0.1% |
| `notched_plate` | /MAT/LAW36 tabulated plasticity + /FAIL/BIQUAD, element deletion, self-impact /INTER/TYPE7 (M4) | Double-edge-notch tension coupon: plasticity localizes at the notch tips, the crack runs element-by-element through the ligament (watch the `OFF` cell field), full separation; the self-contact drops the deleted elements' segments so the crack faces are truly free; energy error ~0% |
| `spot_weld` | /INTER/TYPE2 tied contact (M4): lap joint of two shell strips, offset ties, /GRNOD/BOX | The pull transfers through the tied patch in single-lap shear; CONTACT energy stays exactly zero (a kinematic tie does no work); energy error ~0.03% |
| `edge_impact` | /INTER/TYPE11 edge-to-edge contact (M4): /LINE/SURF edge sets, Istf=2, Igap=1 | A strip dropped edge-first across a supported strip bounces off the crossing point — contact happens between the nodes, where node-to-surface interfaces are blind; energy error a few % over a 23k-cycle /DT 0.9 run |
| `rigid_impactor` | /RBODY rigid body (M5) with /ADMAS ballast, /INTER/TYPE7 vs a clamped shell panel, /GRAV, /SECT + /TH/SECT | A rigid brick block (one 6-DOF body — its bricks never deform) drops onto an aluminium panel, dents it and bounces/rocks; the mid-panel section force spikes at impact and rings down (columns `S1_*` in the T01); energy error a few % at /DT 0.9 |
| `gas_piston` | /EOS/IDEAL-GAS on a LAW1 host (M6), /IMPDISP piston, /STATE/DT snapshots, **restart chaining** (`GASPISTON_0002.rad` resumes `_0001.rst`) | An air column compressed to half volume, then held across two chained runs: the pressure lands on the adiabat p₀·2^1.4 = 2.64 bar within 0.05%, and run 2 continues cycles, energies and T-file numbering exactly where run 1 stopped; energy error 0.00% |
| `implicit_cantilever` | **/IMPL implicit STATICS (M8)** — /SHELL BT4 cantilever, /CLOAD tip load, the Newton–Raphson static driver (not the explicit loop) | A steel plate cantilever loaded transversely at the tip: the run steps the LOAD FACTOR (not a physical time), the listing prints one line per load increment (iterations + residual norm), and the tip deflection matches Euler–Bernoulli `F·L³/3EI` ≈ 1.90 mm to < 0.5 % — each increment converging in a single Newton step (linear elastic). Needs SciPy (`pip install -e ".[implicit]"`) |
| `snap_through` | **/IMPL/ARCL arc-length continuation (M9)** — /TRUSS von Mises two-bar shallow truss, /IMPL/NONLIN geometric nonlinearity, Riks/Crisfield constraint | The classic snap-through problem: the load factor climbs to the closed-form limit point `P(y) = −2EA·ln(L/L₀)·y/L` (≈ 0.63 kN), then the listing shows it DECREASING — even going negative — along the unstable branch, turning at the mirrored limit point and recovering to the full load on the snapped (bars-in-tension) branch. Pure load control (swap /IMPL/ARCL for /IMPL/NONLIN) cannot trace it: just past the peak Newton grinds (18 iterations) and LEAPS discontinuously to the far branch, never sampling the descending/negative-load path. Needs SciPy |
| `implicit_pendulum` | **/IMPL/DYNA implicit DYNAMICS (M10)** — Newmark trapezoidal rule (`/IMPL/DYNA/2` γ=0.5 β=0.25; swap for `/IMPL/DYNA/1 -0.3` to watch HHT-α dissipation drain the ledger) + /IMPL/NONLIN large rotations, /GRAV, /TRUSS | A stiff truss pendulum released from 60° swings through ±60° under gravity — a 120° rotation marched at dt = 3.2 ms, ~150× the explicit stability limit (the bar's wave-transit dt is 0.02 ms): ~240 steps at 3-4 Newton iterations each, where the leapfrog would need ~35,000 cycles. The tip crosses the vertical at the elliptic-integral quarter period T/4 ≈ 170 ms — 7.3% later than the linear-pendulum prediction (the closed form tests/test_m10_impdyn.py asserts to 0.5%) — and the trapezoidal rule holds the energy balance ≈ 0% with zero numerical damping. Needs SciPy |
| `implicit_ringdown` | **M11 implicit COMPLETENESS** — a MIXED-element implicit model (/BEAM mast + /SH3N antenna panel + /TRUSS brace + /SPRING guy: the element-tangent set is complete since M11), `/IMPL/DYNA/DAMP` Rayleigh damping C = a·M + b·K, automatic time-step control (imp_dt.F) armed | A braced instrument mast kicked by a step side force rings down onto its own static answer: the tip overshoots to ~1.38 mm, oscillates at the ~13 ms first sway period with ζ ≈ 8% Rayleigh damping (amplitude ×0.6 per cycle) and settles to the /IMPL static deflection ~0.82 mm within 0.2% after 120 ms; the termination page books the transient's energy in the RAYLEIGH DISSIPATION ledger (DY_EDAMP analogue) while ENERGY BALANCE stays 0.00% — dissipation accounted, not lost. Needs SciPy |
| `implicit_press` | **M12 implicit CONSTRAINTS & CONTACT** — an /RBE2 rigid punch (all its nodes condensed onto a standalone "ram" master, rbe2_imp0.F-style: watch the `CONDENSED EQUATIONS` listing line) pressed onto an elastic pad through /INTER/TYPE7 penalty contact solved INSIDE the Newton loop (i7ke3.F: contact force in the residual at the trial configuration, active-set gap tangent + closest-point curvature in K) | A 4 kN press stroke in ten static load increments, 3 Newton iterations each: the steel punch stays exactly rigid (one free DOF — the ram's guided z stroke), the polymer pad dents ~0.038 mm under ~0.011 GPa peak contact pressure, and the active set (which punch-underside nodes touch) is re-decided inside every iteration. The generator docstring documents the mesh-alignment pathology of node-to-segment contact (why the punch mesh is deliberately NOT grid-aligned with the pad). Needs SciPy |
| `implicit_clamp` | **M13 implicit FRICTION** — the M12 press punch loaded SIDEWAYS below the Coulomb cone: /INTER/TYPE7 with mu = 0.3 solved inside the Newton loop (the i7kfor3.F incremental RETURN MAPPING: stick = tangential penalty spring on the slip increment, slip = radial return to the cone with its consistent nonsymmetric tangent; anchors committed per converged increment) | Two-phase loading: 4 kN press over load factor 0→0.5, then a 0.8 kN lateral push (< mu N = 1.2 kN) over 0.5→1 on a ram whose guide leaves the x slide FREE — only friction holds it. The punch creeps ~0.012 mm (pad shear + the stick state's micro-slip) and STOPS; the pad's integrated shear resultant equals the applied 0.8 kN exactly. Raise the push above the cone and the run fails LOUDLY (no static equilibrium for a sliding clamp — see the generator docstring). Needs SciPy |
| `snap_catch` | **M14 arc length WITH CONTACT** — the snap_through von Mises truss with an /INTER/TYPE7 stop parked below the apex's snap path: /IMPL/ARCL traces the equilibrium path while the contact force joins the corrector's residual and the active-set tangent joins both auxiliary solves (combining ARCL with contact/constraints was a loud M12 refusal, removed in M14) | The trace climbs to the ~0.63 kN limit point, turns the corner down the unstable branch (load factor negative — pure load control can't sample it), then the apex lands on the stop at y ≈ −15 mm: the active set changes INSIDE the corrector, the path stiffens, the load factor climbs back to 1.0 and the truss rests ON the pad at the closed-form truss + penalty-spring equilibrium (~9 mm above the free far-branch answer). Needs SciPy |
| `modal_mast` | **M16 MODAL analysis** — the cantilever mast (20 /BEAM elements) with `/IMPL/EIGV`: the free-vibration eigenproblem `(K − ω²M)φ = 0` on the CONSISTENT (Rayleigh-beam) element mass — the eigensolver of `implicit/modal.py`, run after a zero-load static step exactly as `/IMPL/BUCKL` runs after its prestress | The listing's "NATURAL FREQUENCIES COMPUTATION" block prints the six lowest frequencies: a DEGENERATE bending pair f₁ ≈ 0.01448 (Iyy = Izz → bending about x and y ring together), the next bending pair f₂ ≈ 0.0906, then torsion/axial — matching the Euler–Bernoulli roots (β₁L = 1.875, β₂L = 4.694) to < 0.3 % at 20 elements. The CONSISTENT mass over-predicts and converges from above on refinement (the lumped mass under-predicts — the bracket `tests/test_m16_modal.py` checks); add `/IMPL/EIGV/STRS` after a tensile preload to watch the frequencies stiffen (a tension-tuned string / spinning shaft). Needs SciPy |
| `modal_frf` | **M17 MODAL-SUPERPOSITION dynamics** — the `modal_mast` cantilever driven by a unit lateral harmonic tip force (a shaker), `/IMPL/FREQ` sweeping the forcing frequency across the first two bending resonances: the complex modal FRF `qᵢ(Ω) = (φᵢᵀF)/(ωᵢ² − Ω² + 2 i ζᵢ ωᵢ Ω)`, `u(Ω) = Σφᵢqᵢ(Ω)` of `implicit/modal_response.py`, built on the M16 eigenpairs (a PORT card — the open-source engine has NO frequency-domain path). Companion `/IMPL/MODAL/DYNA` runs the mode-superposition TRANSIENT with the exact Nigam–Jennings recurrence | The "FREQUENCY RESPONSE (harmonic)" block prints the sweep band and the RESONANCES the FRF peaks sit on — the degenerate bending pair f₁ ≈ 0.0145, f₂ ≈ 0.0906 (kHz). At each resonance the tip amplitude spikes to 1/(2ζ) = 50× its static deflection with the half-power bandwidth Δω/ω = 2ζ, and the phase rolls through 180° across each peak (`tests/test_m17_modalresp.py` asserts the peak, bandwidth, and resonance coincidence). The complex FRF is stored on `model.implicit_result.freq_response`; with ζ set per-mode by a uniform value, a (frequency, ζ) table, or the Rayleigh map from `/IMPL/DYNA/DAMP` α,β. Needs SciPy |
| `complex_modes` | **M18 COMPLEX / DAMPED modes** — a non-classically-damped spring-mass chain (4 links, one viscous dashpot on the FIRST link only), `/IMPL/CEIGV`: the quadratic eigenproblem `(λ²M + λC + K)φ = 0` solved through the SYMMETRIC state-space linearization `A z = λB z` (`implicit/complex_modal.py`), with `C` the M18 assembled damping (the /PROP/SPRING dashpot + any Rayleigh α M + β K). Companion `/IMPL/CEIGV/FRF` sweeps the damped complex FRF (a PORT card — the open-source engine has NO complex/damped eigensolver) | The "COMPLEX / DAMPED EIGENVALUES" block prints each mode's `λ = −ζω ± iω_d`: natural frequency, DAMPED frequency, damping ratio ζ and decay rate. The localized dashpot damps the modes UNEQUALLY (ζ ≈ 4.0 %, 8.3 %, 5.5 %, 0.65 % — NOT monotone in frequency), the fingerprint of NON-PROPORTIONAL damping a classical Rayleigh `C` cannot produce, and the complex mode shapes carry a DOF-to-DOF PHASE LAG (the masses reach their extremes at different instants). The `/FRF` sweep's `U(Ω)` has FINITE resonant peaks (poles at the complex `λ_i` — a decaying FRF), stored on `model.implicit_result.complex_frf`. `tests/test_m18_cmplxmodes.py` asserts the closed-form 2-DOF roots, the classical-reduction limit, the state-space biorthogonality, and the complex-mode transient matching a direct Newmark march where M17's real-mode superposition provably errs. Needs SciPy |
| `brake_pad` | **M15 friction MODELS** — the implicit_clamp geometry with a PRESSURE-DEPENDENT friction card: /INTER/TYPE7 Ifric = 1 (MFROT 1, mu(p) = mu0 + C1·p — the i7for3.F law, contact/friction.py) solved in the implicit Newton loop with the consistent mu'(p) coupling tangent (implicit/contact.py) | "A brake pad grips harder the harder you press": with the base mu0 = 0.15 alone the 0.8 kN lateral push would EXCEED the cone (mu0·N = 0.6 kN — set Ifric = 0 and the run fails loudly, no static equilibrium), but the 4 kN press pressure lifts mu(p) to ~0.35–0.4 and the clamp HOLDS — 20 increments at 3 Newton iterations each, the punch creeping by the stick micro-slip and stopping. The same card runs under the explicit engine (mu(p, v) kinetic law + optional IFQ filtering). Needs SciPy |
| `random_vibration` | **M19 RANDOM / SPECTRAL (PSD) response + RESPONSE SPECTRA** — a base-excited 5-mass instrument stack (shaker table / seismic model), `/IMPL/PSD/BASE`: the stationary response PSD `S_uu(Ω) = |H(Ω)|² S_aa(Ω)` through the M16 participation-fed base-excitation FRF (`implicit/random_response.py`), and `/IMPL/RSPEC`: the design-response-spectrum modal combination `rᵢ = Γᵢ Sa(ωᵢ)/ωᵢ²` by SRSS and CQC (Der Kiureghian 1981, `implicit/response_spectrum.py`). Both PORT cards — the open-source engine has NO random-vibration / response-spectrum path (`freimpl.F` is time-domain only) | The "RANDOM / SPECTRAL (PSD) RESPONSE" block reports the RMS relative displacement `σ_u = √m₀`, the spectral moments m₀/m₁/m₂ and the mean zero-crossing rate `ν₀ = (1/2π)√(m₂/m₀)` — which sits near the fundamental (~32) since the response is narrow-band-dominated, with the peak rate `ν_p = (1/2π)√(m₄/m₂)` above it. The "RESPONSE SPECTRUM" block prints the participation table (Γᵢ, Sa(ωᵢ), the modal peak Γ Sa/ω²) and the SRSS and CQC peak envelopes; for this well-separated stack CQC ≈ SRSS (the "MAX \|CQC − SRSS\|" line is ~0.01 %) — CQC's cross-terms only matter for CLOSELY-SPACED modes (the M19 tests assert the gap on a near-degenerate tuning-fork pair). The white-noise SDOF variance is validated against the closed form σ² = S₀/(2ck); stored on `model.implicit_result.random_response` / `.response_spectrum`. Needs SciPy |
| `spectral_fatigue` | **M20 RANDOM-VIBRATION (SPECTRAL) FATIGUE** — the SAME base-excited 5-mass instrument stack the M19 example shakes, now asking how long the critical element lasts: `/IMPL/FATIG/BASE` recovers a STRESS PSD from the M19 machinery (the per-mode stress modes `σᵢ = (element stress operator)·φᵢ` recovered by running the force kernels on each mode shape read-only, `H_σ(Ω) = Σᵢ σᵢ qᵢ(Ω)`, `S_σσ(Ω) = |H_σ|² S_aa`, `implicit/random_response.py`), then evaluates the S-N curve `N = C·S^−m` under a Miner sum by the narrow-band (Bendat 1964), Dirlik (1985), Wirsching–Light (1980) and Tovo–Benasciutti (2005) estimators (`implicit/spectral_fatigue.py`), plus a seeded Monte-Carlo rainflow cross-check. A PORT card — the open-source engine has NO frequency-domain / spectral-fatigue solver (`freimpl.F` is time-domain only; its sole `PSD` token is `IMUMPSD`, a MUMPS flag) | The "RANDOM-VIBRATION (SPECTRAL) FATIGUE" block reports the CRITICAL stress channel (`springs#1:N` — the base spring, which carries the whole stack's inertia), the RMS stress `σ = √m₀`, the crossing/peak rates `ν₀`/`ν_p` and the irregularity factor `α₂` ≈ 0.52 (a somewhat wide-band, two-mode response), then a damage-rate / life / equivalent-stress table for all four estimators: **narrow band is the most conservative** (shortest life), **Dirlik relaxes it** (the wide-band correction, ≈ 0.84× the narrow-band damage here), and Wirsching–Light / Tovo–Benasciutti bracket Dirlik. The **Monte-Carlo rainflow** row (a Gaussian history synthesised from the PSD, ASTM E1049 counted, Miner-summed) agrees with Dirlik to within ~20 % — the time-domain answer the spectral methods approximate. Stored on `model.implicit_result.fatigue`. Needs SciPy |
| `multiaxial_fatigue` | **M21 MULTIAXIAL / CRITICAL-PLANE SPECTRAL FATIGUE** — a base-clamped SOLID-brick cantilever (6 /BRICK hexa8) driven by a SKEW (bending + shear) random tip-force PSD, so the clamped-root elements see a genuinely MULTIAXIAL stress state (σ_xx bending + σ_zx transverse shear + off-axis σ_yy/σ_xy). `/IMPL/FATIG/MULT` keeps the FULL 6-component Voigt stress FRF `H_σ(Ω)` (nf,6) per element (the M20 vector stress modes reused read-only), forms the stress-tensor cross-PSD `S_σσ = H_σ S_ff H_σᴴ` (a 6×6 Hermitian matrix per frequency), and reduces it to a scalar equivalent-stress PSD three ways — equivalent VON MISES `trace(Q·S_σσ)` (Preumont–Piéfort 1994 / Pitoiset–Preumont 2000), MAX-NORMAL and MAX-SHEAR CRITICAL PLANE (Carpinteri–Spagnoli / Cristofori–Susmel–Tovo, searched over candidate planes) — running the four M20 estimators (`implicit/multiaxial_fatigue.py`) on each, plus a MULTIVARIATE Monte-Carlo cross-check (Cholesky/eigen of `S_σσ` → correlated Gaussian component histories → project → ASTM E1049 rainflow). A PORT sub-card — the open-source engine has NO frequency-domain / spectral-fatigue solver of any kind, scalar OR multiaxial (`freimpl.F` is time-domain only) | The "MULTIAXIAL / CRITICAL-PLANE SPECTRAL FATIGUE" block reports the CRITICAL ELEMENT (`bricks#1` — the clamped root), then three reduction sub-blocks (EQUIVALENT VON MISES, MAX-NORMAL, MAX-SHEAR) each with its RMS equivalent stress (~0.02 GPa = 20 MPa), crossing/peak rates, irregularity factor `α₂` ≈ 0.73 (two-mode-group, wide-band) and the four-estimator damage/life table. The **von-Mises life is the SHORTEST** (it aggregates all deviatoric components, ≈ 5×10⁷ ms); the critical-plane lives are longer (each counts one resolved scalar). The **critical-plane normals are the multiaxial signature**: the max-normal plane is TILTED (~[0.68 0.18 0.71], NOT a coordinate axis — a purely uniaxial stress would put it on the loading axis), the max-shear plane is the cross-section plane (normal ~ the beam axis). The **Monte-Carlo** row (correlated-history rainflow on the shear plane) agrees with that plane's Dirlik within scatter. Stored on `model.implicit_result.fatigue` (the M20 dict, extended with `multiaxial`). Needs SciPy |

Run any example with:

```bash
pyradioss-starter -i <NAME>_0000.rad     # writes <NAME>_0000.out + .rst
pyradioss-engine  -i <NAME>_0001.rad     # writes <NAME>_0001.out, T01.csv, A*.vtk
```

Post-process:
* `<NAME>T01.csv` — plot with anything (column headers in the file),
* `<NAME>A*.vtk` — open the file *group* in ParaView, press Apply, and use
  the animation controls (VONM = von Mises stress, EPSP = plastic strain).

Units in all decks: mm / ms / kg  →  forces in kN, stresses in GPa
(a standard consistent Radioss unit system).
